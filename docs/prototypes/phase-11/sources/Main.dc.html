BlindVault Prévia

Seu cofre de senhas fica nos seus aparelhos. Só neles.

Não existe conta nem servidor. Os aparelhos trocam dados direto entre si, quando você aproxima os dois.

Ninguém, nem o BlindVault, consegue redefinir sua senha local ou recuperar o cofre por você.
A Frase de Recuperação e um backup são o único jeito de trazer o cofre de volta.

Como você quer começar?

Criar um cofre novoPrimeira vez no BlindVault. Usar o cofre de outro aparelhoO aparelho que já tem o cofre entrega uma cópia para este. É o pareamento. Restaurar de um backupAbra um arquivo .bvault com a Frase de Recuperação ou a senha de exportação.
