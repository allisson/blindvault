Eighth pre-release of BlindVault: vaults and backups made with a 0.x version may not open in a later version, and no migration is planned for them (D177). It follows the hands-on test of v0.7.0, which found Settings crowded on one page and the pairing and sync screens unclear about where the user stands. It is for another hands-on test before the Security Gate of Phase 8 (D244). Before you use it, read [docs/limitations.md](../limitations.md).

What changed since v0.7.0:

- Settings: an index of pages in groups, each page with its own screen and a way back to the index (D252);
- pairing, joining, re-admission and sync: a wizard, one step at a time under "Step N of M" with a bar, a box saying what to do on the other device, and Cancel while there is something to cancel; "Same network only" and the STUN list move into "Advanced options" (D253);
- create, restore, reset the password, regenerate the phrase, re-found, merge and import: the same wizard; creating a vault can now be cancelled, which drops the phrase and returns to the three starts (D253).

The service worker is unchanged since v0.1.0.
