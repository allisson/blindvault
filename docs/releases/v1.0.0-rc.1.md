First release candidate of BlindVault 1.0, for the Security Gate: the reproducible build is validated on this release, and the external cryptographic and protocol review ([docs/review-brief.md](../review-brief.md)) and the browser matrix ([docs/browser-matrix.md](../browser-matrix.md)) run against it. It is still a pre-release: vaults and backups made with it may not open in a later version, and no migration is planned for them (D177, D194). Before you use it, read [docs/limitations.md](../limitations.md).

The app is unchanged since v0.7.3 apart from its version: the changes since then are tests and documentation for the Security Gate.

The service worker is unchanged since v0.1.0.

Served at https://blindvault.allisson.dev.
