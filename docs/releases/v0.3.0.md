Third pre-release of BlindVault: vaults and backups made with a 0.x version may not open in a later version, and no migration is planned for them (D177). It brings Phase 4 (pairing) for the Gate C manual run on phones.

What changed since v0.2.0:

- pairing: a new device joins a vault over a direct WebRTC connection, with no server holding vault data. Both devices exchange a payload by QR code or by copy/paste, show the same six-digit number, and the user confirms it on both before any key moves. The device holding the vault asks for its local password again;
- replace by pairing: from the unlock screen, a device holding a locked vault replaces it with another device's vault, only after the user confirms;
- re-admission: from Settings › Devices, a device restored from a backup is re-admitted by another device of the vault, and both merge their records;
- the STUN list used by pairing can be edited on every pairing screen, or pairing can be limited to the same network;
- erase: "Erase this vault from this device", from Settings or from the unlock screen;
- a Save followed at once by another navigation no longer opens the saved item in place of the screen the user chose.

There is no continuous sync between devices yet (Phase 5): after a pairing, each device changes its own copy, and a re-admission merges them by hand.

The service worker is unchanged since v0.1.0.
