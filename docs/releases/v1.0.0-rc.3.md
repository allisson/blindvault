Third release candidate of BlindVault 1.0. It adds attachments, the browser extension with stored passkeys, and the Android app, the first release to publish an APK. It is still a pre-release: vaults and backups made with it may not open in a later version, and no migration is planned for them (D177, D194). Before you use it, read [docs/limitations.md](../limitations.md).

What changed since v1.0.0-rc.2:

- attachments: files kept in an item, encrypted, synced between devices and kept in backups, with sync and pairing at protocol version 2, which refuses a device of an earlier version and tells it to update, and backups at format version 2, while backups of format version 1 still restore (D278, D279);
- the browser extension for Chrome and Firefox: password autofill from the popup and the shortcut, and stored passkeys, ES256 and EdDSA (D283 to D285, D288); its packages are attached to this release;
- the Android app: the same app in a WebView shell, biometric unlock with a key held in the Android Keystore, pairing and sync, a reproducible APK signed offline by the maintainer and distributed outside Google Play (D290 to D299);
- unlock checks the item versions after the vault opens and holds them as summaries (D277);
- the last backup is recorded only once its file is saved (D291), and the device that shows the pairing code holds the camera before it starts gathering (D296).

The service worker is unchanged since v0.1.0.

Served at https://blindvault.allisson.dev.
