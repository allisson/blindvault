Second release candidate of BlindVault 1.0, for the Security Gate. It holds the fixes from the pre-review of v1.0.0-rc.1 (the Findings of [docs/review-brief.md](../review-brief.md)), and the external cryptographic and protocol review runs against it. It is still a pre-release: vaults and backups made with it may not open in a later version, and no migration is planned for them (D177, D194). Before you use it, read [docs/limitations.md](../limitations.md).

What changed since v1.0.0-rc.1:

- auto-lock and the hidden-app lock also run while a vault is created or restored, and count by the wall clock, so a frozen page or a suspended device locks once it resumes (D263, R-02, R-03);
- a paired device can no longer send an item that breaks later merges, hide a device's retirement, or skip the trash with a tombstone (D260, D261, D262, R-01, R-04, R-05);
- before a peer is authenticated, what it can queue unread is capped (D264, R-06);
- startup no longer opens a replaced vault that another app window still holds (V-01);
- a Local Config that names another vault is treated as corrupt, a few errors of the import, the restore and the export are handled, and keys and plaintext are wiped in more places (R-07, R-08, R-10, R-11, N-10).

The service worker is unchanged since v0.1.0.

Served at https://blindvault.allisson.dev.
