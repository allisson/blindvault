Second pre-release of BlindVault: vaults and backups made with a 0.x version may not open in a later version, and no migration is planned for them (D177). It closes Phase 3 (PWA and integrity).

What changed since v0.1.0:

- onboarding: the first screen says there is no account and no server, and offers three starts (create, pair, restore); in a plain Safari tab it first advises installing the app; after a creation or a restore, "Vault ready" lists the next steps, each opening its section of Settings;
- layouts: drafts, revealed secrets, the selection and the search survive a resize; the tablet folder drawer; the system back goes one screen back; N starts a new item; 44 px touch targets on a coarse pointer;
- storage state: whether storage is persistent, how much the vault uses, and warnings when it runs low;
- self-hosting: instructions and tested nginx and Caddy configurations in `deploy/`.

Pairing is not available yet: the pair start explains how to move a vault with a backup until Phase 4.

The service worker is unchanged since v0.1.0.

Served at https://blindvault.allisson.dev.
